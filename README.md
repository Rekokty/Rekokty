# Wspólny Jadłospis

Aplikacja w jednym pliku (`index.html`), która:

- układa jadłospis na 1–14 dni dla kilku osób, każda z własnym limitem kalorii,
- uwzględnia dietę bez mięsa, bez glutenu, bez laktozy i wykluczone produkty,
- liczy z jadłospisu wspólną listę zakupów z odhaczaniem i ręcznie dopisanymi pozycjami.

Opublikowana jako artefakt Claude korzysta ze wspólnej bazy danych, więc wszyscy
z dostępem widzą zmiany na żywo. Otwarta jako zwykły plik zapisuje dane tylko
w przeglądarce na danym urządzeniu.
